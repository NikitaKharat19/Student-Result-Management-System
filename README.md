# Student Result Management System

## Objective
The Student Result Management System is a Python-based command-line project used to manage student result information.

## Features
- Add student result
- Calculate total marks
- Calculate percentage
- Calculate grade
- Display Pass/Fail status
- Search and display student result
- Show all student records
- Store data in Excel file

## Technologies Used
- Python
- OpenPyXL
- Excel
- VS Code
